# 待测试

- PSD 工作台新增运行中任务“终止任务”按钮，后端新增 `POST /api/v1/psd-tasks/:id/cancel` 取消接口，会取消文本模型请求或正在执行的 Python PSD 脚本，并把任务状态保存为 `canceled`；左侧历史记录标题区新增“新增”按钮，用于清空当前任务并回到新任务上传状态。需要验证运行中任务可终止、终止后轮询不再继续、状态显示“已终止”、产物区不展示旧预览、历史记录可重新点开终止任务，以及点击“新增”后能重新选择图片创建任务。
- “我的素材”里的图片素材卡片和详情抽屉新增“生成PSD”按钮；点击后会用该素材原图创建 PSD 任务，写入 PSD 工作台历史并自动跳转到 `/psd` 打开新任务。需要验证图片素材可直接发起 PSD 生成、跳转后 PSD 工作台能显示原图与任务状态，文本/视频素材不出现该入口，任务创建失败时会停留当前页并显示错误。
- Electron 桌面端启动流程改为先创建主窗口并显示本地 loading 页，再在后台启动 Go API 和 Next.js 服务；服务健康检查不再固定等待 2 秒，启动完成后自动跳转到 `/login` 并移除 loading。需要重新打包 exe 后验证双击程序会立即出现 loading，服务启动完成后自动进入登录页，启动失败时窗口内会显示失败原因并弹出错误提示。
- 新增 `PSD工作台` 页面和三个本地 Go 接口：`POST /api/v1/psd-tasks` 创建异步任务、`GET /api/v1/psd-tasks/:id` 查询任务状态和耗时、`GET /api/v1/psd-tasks/:id/files/:name` 获取原图、预览图、PSD、图层 ZIP、manifest 和生成配置。任务会保存到应用数据目录 `psd-tasks/{taskId}/`，Go 会使用本地已同步的默认文本模型识图生成 `layers.json`，并固定携带 `reasoning_effort=high`，再调用内置 `poster-layer-psd` skill 和 `python-bin` 生成产物；任务元信息会写入同目录，应用重启后也可从磁盘恢复历史任务和产物链接。PSD 页面新增左侧历史记录、中间原图、右侧任务状态与产物下载的三栏布局，并在内容超出视口时支持页面内纵向滚动；切换页面后由全局轮询器每 3 秒刷新运行中任务，完成或失败时通过全局通知提示。PSD 图层 JSON 提示词已按 `poster-layer-psd` 的 schema 和拆层策略补充支持字段、图层顺序、extract/type 枚举、坐标约束、文字安全边距和同一文案框内主副文案合并规则。需要在桌面端验证上传图片、开始任务、切换到其他页面后任务继续处理并弹出完成提示、返回 PSD 页面可从历史打开任务、重启应用后历史任务仍可显示原图和预览、小窗口下可滚动到底部、原图回显、成功预览、产物下载、生成的 `layers.json` 字段和坐标更稳定、PSD 预览里的中文/英文/数字文字不被裁切、同一牌匾或按钮内的上下文案不被拆成割裂图层，以及模型失败、Python 依赖缺失或脚本失败时的错误提示。
- 画布库新增“搜索画布名称”输入框，会按画布标题实时过滤当前浏览器本地保存的画布列表；无匹配结果时显示空结果提示。需要验证输入完整/部分名称能筛出对应画布，清空搜索后恢复完整列表。
- 登录页新增“记住账号密码”复选框；勾选并登录成功后会把用户名和密码保存到浏览器本地，下次打开登录页自动回填，未勾选登录会清除已保存内容。需要验证勾选登录、重启/刷新后回填，以及取消勾选登录后不再回填。
- Electron 云端登录态现在会记录云端 `accessTokenExpiresIn`，在 access token 接近过期或收到 401/未登录响应时，使用本地加密保存的 refresh token 自动调用云端 `/api/infinite-canvas/auth/refresh` 续期，并更新轮换后的 refresh token；生图、编辑、带图问答、视频、音频、参考素材上传和云端模型配置刷新会先获取有效 access token，过期后自动重试一次。客户端不再每 30 秒轮询 `/auth/me`，只在窗口重新获得焦点和实际业务请求时验证云端会话。需要保持 exe 登录超过 15 分钟后验证顶部账号不掉线，各生成入口和“刷新云端控制 LLM 配置”仍可正常请求；后台强制下线或禁用账号后，切回窗口或发起下一次云端请求时应清空本地登录态并要求重新登录。
- 云控 `vben-admin-monorepo-template` 新增桌面端模型公开配置接口 `/api/infinite-canvas/settings/model-channel`，桌面端登录后直接请求 Python 获取 `enable_infinite_canvas=true` 的可用模型、展示名和默认模型，不再由本地 Go 直连外部 PostgreSQL 或执行 `/settings/cloud-sync`。需要在云控模型列表里打开指定模型后，验证 exe 端点击“刷新云端控制 LLM 配置”只出现已开启模型，模型下拉显示云端名称但生成请求仍使用真实 `modelName`。
- 顶部导航和画布右上角现在新增了明确的“检测版本”按钮；点击后会主动请求版本检测，并分别显示“发现新版本 / 当前已是最新版本 / 检测失败，请稍后重试”三种状态。Electron 主进程同时补上了 `check-update` 与 `download-update` IPC：检测会按当前桌面端实际 `platform/arch` 直接请求云端 Python `/api/infinite-canvas/updates/latest`，并且只有远端版本高于当前安装版本时才显示更新信息；Windows 桌面端点击“立即更新”后会在 exe 内部下载安装包，弹窗显示下载进度，下载完成后提示即将启动安装程序并关闭当前应用，再拉起下载好的安装器。非 Windows 或非桌面端仍保留浏览器下载兜底。需要在已安装 `0.0.4`、远端存在 `0.0.5` 发布记录时验证首页和画布页都能手动检测出新版本；远端无更高版本时显示“当前已是最新版本”；接口异常时显示失败提示；Windows 点击“立即更新”后不再弹浏览器下载，而是在弹窗内显示进度、下载完成后关闭旧版并打开安装器。
- Electron 安装包现在会显式携带 `desktop/resources/env.ini`，并且生产环境主进程读取打包环境文件时会忽略其中的 `NODE_ENV`，避免误切到开发路径；需要重新打包并安装 exe 后验证 `window.desktopApp.getCloudBaseUrl()` 能读到 `INFINITE_CANVAS_CLOUD_BASE_URL`，登录页不再提示“未配置云端控制服务地址”。
- `vben-admin-monorepo-template` 的“系统全局设置 -> OSS 存储配置”新增桌面版无限画布云端上传配置区：继续复用根级 `targetPath` 作为前缀，新增 `RAM Role ARN`、`STS 有效期秒数`、`Bucket 覆盖值（可空）`，并显示固定的 `infinite_canvas/{user_id}/{yyyy}{mm}{dd}/{random}.{ext}` 路径预览；Python 保存 `oss_config` 时会自动规范化 `targetPath` 和 `infiniteCanvasDesktop` 字段。当前 `RAM Role ARN` 留空时，页面会显示“现有永久凭证模式”作为临时兼容；填写后再切正式 STS 模式。需要验证设置页加载旧数据、保存后自动补齐新字段、`targetPath=daily_orange_ai/` 时预览路径正确，且旧 OSS 测试连接仍可用。
- 桌面云端生图已接入真实票据交换链路：前端远程渠道在桌面云端登录模式下会先向云端创建 `generation ticket`，再把 `ticket_id/ticket_token/device_id/reference_images/mask` 交给本地 Go；Go 会向云端交换一次性快照、按云端下发的最终 Prompt 和图片模型配置生成图片、上传到 `oss://decent-lancheng/daily_orange_ai/infinite_canvas/{user_id}/{yyyy}{mm}{dd}/{random}.png`、再回写 `complete/fail`。当前 `RAM Role ARN` 留空时走临时永久凭证模式，已填写 `RAM Role ARN` 时会明确报“STS 临时凭证模式尚未接通”。需要重启云端 `ai-server` 和本地 Go/Next 进程后验证 `/image`、画布普通生图、画布参考图生图、局部编辑 mask、生图失败回写，以及 OSS 中对象路径和管理端 `desktop_generation_tasks` 状态是否一致。
